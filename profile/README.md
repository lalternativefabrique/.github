# L'Alternative Fabrique

Most of the software a small European organisation runs on is hosted outside Europe, billed per seat, and closed to inspection.
We build applications hosted in the EU, and we publish the building blocks they share.

## Open building blocks

| Repository | What it is |
| --- | --- |
| [sklp](https://github.com/lalternativefabrique/sklp) | Deployment supervisor for single-node and multi-node stacks (BSL 1.1) |
| [stack](https://github.com/lalternativefabrique/stack) | Scaffolder for a Go DDD backend + TanStack web app, wired to the `sklp` workflow |
| [eventkit](https://github.com/lalternativefabrique/eventkit) | Go primitives for event-driven, event-sourced, CQRS applications |
| [searchkit](https://github.com/lalternativefabrique/searchkit) | Go libraries for finding and admitting content |
| [editorkit](https://github.com/lalternativefabrique/editorkit) | `@lalternative/editor`: shared TipTap editor for React and React Native |
| [spore-sdk](https://github.com/lalternativefabrique/spore-sdk) | SDKs for the [Spore](https://sporee.fr) transactional email API |
| [packages](https://github.com/lalternativefabrique/packages) | Shared Go and npm packages |

## What is not here

The applications themselves are private for now. What is published above is what we are willing to maintain in the open.
